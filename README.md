# Urbano Vitolo · Estudio Jurídico

Una web para entender, sin tecnicismos, qué puede hacer el estudio por vos y cómo dar el primer paso.

El sitio recorre las áreas en las que trabajamos —laboral, civil, daños y perjuicios, sucesiones y divorcios, y asesoramiento comercial— y explica cada una con ejemplos concretos. No hace falta saber si tu problema es "laboral" o "civil": podés contar qué te pasa y desde ahí vemos juntos qué sigue.

También están las respuestas a las preguntas que aparecen siempre: cómo es la primera consulta, qué conviene tener a mano y si se puede hablar de forma virtual. Cuando quieras, alcanza con escribinos por WhatsApp.
